# Ecommerce Backend

Backend API for my ecommerce frontend project, built with Node.js and Express.
Originally based on the SuperSimpleDev course backend.

## Related
- [Frontend Repo](https://github.com/RojanThami/ecommerce-frontend)

## Set up
1. Make sure you have NodeJS installed (version 22+)
2. Run `npm install`
3. Run `npm run dev`
